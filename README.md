# Parcel Box Counter

เว็บแอปพลิเคชันสำหรับตรวจนับจำนวนกล่องพัสดุ (1-9 กล่อง) จากภาพถ่าย พัฒนาด้วย Python ล้วน (FastAPI) โดยนำหลักการทาง Linear Algebra (2D Affine Transformation, Laplacian Filter, SVD) มาใช้งานร่วมกับ Multi-Class MLP

---

## การติดตั้ง (Setup)

1. ติดตั้งไลบรารีที่จำเป็น:
```bash
pip install -r requirements.txt
```

---

## วิธีรันระบบ

รันคำสั่ง:
```bash
python server.py
```

เมื่อเซิร์ฟเวอร์เริ่มทำงาน ให้เปิดเว็บบราวเซอร์ไปที่:
**`http://localhost:8001`**

---

## การใช้งานบนหน้าเว็บ

1. **เลือกรูปภาพ:**
   - กดเลือกไฟล์ภาพจากเครื่อง
   - กดเปิดกล้องเพื่อถ่ายภาพสด (รองรับทั้งมือถือและเว็บแคม)
   - หรือกดปุ่ม **"ใช้รูปตัวอย่าง 1 กล่อง"** เพื่อทดสอบทันที
2. **จัดตำแหน่งภาพ (Viewport 400x300):**
   - คลิกแล้วลากเมาส์เพื่อเลื่อนตำแหน่งภาพ (Pan)
   - ใช้ Scroll Wheel หรือแถบเลื่อนด้านล่างเพื่อปรับระดับการซูม (Zoom)
3. **ดูผลลัพธ์:**
   - ระบบจะคำนวณค่า Forward Matrix $[M]$ และ Inverse Matrix $[M^{-1}]$ เพื่อตัดภาพตามตำแหน่งที่กำหนด
   - แสดงผลการทำนายจำนวนกล่อง (1-9 กล่อง) ค่าความมั่นใจ และกราฟแจกแจงความน่าจะเป็น (Softmax) แบบ Real-time

---

## หลักการทำงานคร่าวๆ

1. **2D Affine Matrix:** นำค่าการซูมและเลื่อนตำแหน่งมาสร้าง Matrix $3 \times 3$ เพื่อหา Inverse Matrix $[M^{-1}]$ แล้ว Crop ภาพตามกรอบ Viewport ปรับขนาดเป็น $512 \times 512$
2. **Edge & SVD Subspace:** แปลงภาพเป็น Grayscale, สกัดเส้นขอบด้วย Laplacian Filter, ตัดแสงสะท้อนด้วย Percentile Clipping และใช้ SVD ($V^T$) ลดทอนมิติเหลือ 64 ฟีเจอร์
3. **MLP Classification:** นำ 64 ฟีเจอร์ SVD รวมกับสถิติภาพ 3 ค่า (รวมเป็น 67 ฟีเจอร์) ส่งเข้าโครงข่ายประสาทเทียม ($67 \to 32 \to 9$) ผ่านฟังก์ชัน Softmax เพื่อจำแนกความน่าจะเป็นของจำนวนกล่อง

## โครงสร้างไฟล์สำคัญ

- `server.py` : ไฟล์หลัก รวม FastAPI Backend และหน้าเว็บ Interactive UI ไว้ในไฟล์เดียว
- `predict.py` : ตรรกะการคำนวณทางคณิตศาสตร์และโมเดลทำนาย
- `sample_box.jpg` : รูปภาพตัวอย่างสำหรับทดสอบ
- `requirements.txt` : รายชื่อแพ็กเกจ Python ที่ต้องใช้งาน
- `model/trained_models/session_20261018_082656/` : โฟลเดอร์เก็บไฟล์โมเดล (weights, svd_model.npz, pipeline_config.json)

---

## API Endpoints (FastAPI)

- `GET /` : หน้าเว็บแอปพลิเคชัน
- `POST /predict` หรือ `POST /api/count-boxes` : API สำหรับส่งรูปและพารามิเตอร์ Pan/Zoom เพื่อตัดภาพและทำนาย
- `GET /api/model-status` : ตรวจสอบสถานะการโหลดโมเดล
- `GET /api/sample-image` : ดึงไฟล์รูปตัวอย่าง
